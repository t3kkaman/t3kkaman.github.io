Equivalent to: ```python temp = decorator_method("there") hello_world = temp(hello_world) ``` --- ## ❓ What even is a decorator? > A decorator is just a function that takes a function and returns another function. *More formally:* - It is a higher-order function - It wraps or replaces another function - It runs at definition time, not runtime of your function call ### 🎁 Mental Model (gift edition) - func = your gift 🎁 - decorator = gift factory 🏭 - wrapper = gift box 🎁📦 👉 Important: > The decorator does NOT return the original gift, > > It usually returns a wrapped gift ## 💡 The REAL pattern (you will use this 99% of the time) ```python def decorator(func): def wrapper(*args, **kwargs): # before result = func(*args, **kwargs) # after return result return wrapper ``` --- Section for myself ## ⚠️ Big misunderstanding (let’s fix it) ### ❌ "Decorator must return func" Nope. ### ✅ Correct version: > A decorator must return a callable >
